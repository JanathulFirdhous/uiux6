**Student Name:** Janathul Firdhous A  


##  Project Overview
This project maps out the end-to-end UX design process for a **Hospital Appointment Booking Application**. The objective is to identify critical user pain points—specifically focusing on accessibility, localization, and simplified navigation—and build a structured framework to improve usability, efficiency, and overall user satisfaction.


##  Key UX Steps Covered

### 1. Solution Ideation (Brainwriting Exercise)
Explored multiple low-fidelity feature ideas to streamline user journeys:
*   **One-Click Booking** & **Voice-Based Commands**
*   **Smart Scheduler** & **Emergency Quick Book**
*   **Chat-Based Assistants** & **Symptom Checkers**
*   **Multilingual Support** (Priority focus for localization)

### 2. User Stories
Developed targeted user personas to cover diverse demographics, including:
*   Trusted doctor selection for returning patients.
*   **Native language support for rural demographics.**
*   Simplified navigation layouts for elderly users.
*   Proactive reminders for working professionals.

### 3. Scenario & Context Mapping
*   **User Focus:** Lakshmi, a 54-year-old woman from rural Tamil Nadu learning to use a smartphone.
*   **UX Goal:** Overcoming language barriers and reducing application anxiety through direct, local language localization (Tamil).
*   **Emotional Arc:** Nervous/Confused ➔ Frustrated ➔ Relieved ➔ Confident.

##  Information Architecture (IA) & Site Map
Using an **Open Card Sorting** methodology, the core functionalities were grouped into 5 clear system pillars:

*   **Doctors:** Lists, specializations, ratings, and active availability.
*   **Appointments:** Core booking actions, cancellations, rescheduling, and historical logs.
*   **User Profile:** Personal details, secure medical records, and prescription histories.
*   **Notifications:** Critical health alerts and upcoming consultation reminders.
*   **Help & Support:** FAQs, direct customer care channels, and emergency quick-dials.
